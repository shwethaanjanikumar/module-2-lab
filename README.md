#  GIT AND GITLAB FUNDAMENTALS

The commands that are executed include :
1) Clone the repository : git clone https://github.com/shwethaanjanikumar/module-2-lab.git

2) Create feature branch : git checkout -b feature

3) Commit changes : git status
                    git add README.md
                    git commit -m "Updated README"

4) Push branch : git push -u origin feature

5) Create Pull Request and Commit the changes from the feature branch

6) Merge pull request of the feature with the main and confirmed
